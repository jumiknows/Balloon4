# 2024 Balloon4 source snapshot

This directory preserves the Python source from commit `fcbedee5`, the final repository state before the 2026 cleanup and modernization.

It is historical code.

It includes:

- early single-sensor experiments
- the original all-in-one driver
- the later modular sensor classes
- camera experiments
- RFM9x radio code
- buzzer and microphone experiments

Generated CSV files, lock files, Python caches and recorded video are intentionally not duplicated here.

For the exact historical repository, including generated artifacts and original paths, use the `archive/flight-era-2024` branch or inspect Git history.

The maintained runtime is under `src/balloon4`.
